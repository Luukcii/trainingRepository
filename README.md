# Max's Portfolio

A one-page portfolio with a private admin area. Built with Next.js, Tailwind, Neon Postgres, and Better Auth.

## Run it locally

1. Open the terminal in VS Code: **Terminal → New Terminal**.
2. Type this and press Enter:

   ```
   npm run dev
   ```

3. Open http://localhost:3000 in your browser.
4. To stop it, click the terminal and press **Ctrl + C**.

## Where things are

- `src/app/` — pages (each folder is a URL)
- `src/components/` — the building blocks of each page
- `CLAUDE.md` — rules for Claude
- `LEARNING.md` — what Max has learned so far
